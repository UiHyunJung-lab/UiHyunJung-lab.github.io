## 🛠️ 로그인 기능 수정: 비회원 접근 허용

오늘은 **GistInfoApp**의 로그인 기능을 대대적으로 수정하였다.

### 🆚 기존 vs 변경
* **기존 (Before)**: 앱을 켜자마자 바로 로그인 창이 뜨는 방식. (로그인 필수)
* **변경 (After)**: **비회원(Guest)**으로도 앱을 둘러볼 수 있도록 변경.

### 💡 변경 이유 (Team Feedback)
저번 회의에서 **"기본적인 학식 정보, 시험 정보, 시설 정보 등은 로그인을 하지 않고 봐도 되지 않겠느냐"**는 팀원의 의견이 있었다.
나 또한 그 의견에 동의하였다. 정보성 앱인데 굳이 처음부터 로그인을 강요할 필요는 없다고 판단했기 때문이다.

### 💻 구현 내용
1.  **초기 화면 분기**: 앱 실행 시 [로그인 창]과 **[비회원으로 진행하기]** 버튼을 따로 만들었다.
2.  **접근 권한 제어**:
    * **정보 조회 (학식/시설/시험)**: 로그인 없이 접근 가능.
    * **커뮤니티 (게시판)**: 접근 시 로그인 화면을 띄우고, 재안내를 하는 방식으로 수정.
3.  **UI 개선**: 로그아웃 버튼도 **모달(Modal)**을 이용하여 더 깔끔하게 수정하였다.

<br>

## 👥 팀 협업 현황
다른 팀원들도 각자의 파트에서 기능을 거의 완성해 가고 있다.
* **지스트 도서관** 관련 기능
* **지스트 전체 지도** 관련 기능

이제 모든 팀원들이 각자 맡은 바를 거의 마무리해가는 과정이라 기대와 동시에 걱정도 많다.

<br>

## 🚨 이슈 발생: Git Merge 충돌
개발 막바지에 접어들면서 깃(Git)에서 서로의 코드를 **Merge**하는 과정에서 충돌(Conflict)이 발생했다.

### 💥 충돌 원인 분석
1.  **Main 브랜치 버전 차이**: 팀원들이 예전에 업데이트된 `main` 코드를 기반으로 작업함.
2.  **대규모 리팩토링**: 최근 며칠간 내가 진행한 리팩토링 과정에서 **여러 파일이 동시다발적으로 이동하고 수정**되면서 깃이 파일 변경 이력을 추적하기 어려워짐.

충돌된 코드를 하나하나 수정하는 데 시간이 꽤 소요되겠지만, 이 과정만 잘 넘기면 앱 개발의 큰 산은 넘게 된다.
