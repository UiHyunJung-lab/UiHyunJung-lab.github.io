## 📌 문제 정보
* **문제 번호**: [백준 6064번: 카잉 달력](https://www.acmicpc.net/problem/6064)
* **알고리즘 분류**: 수학, 정수론, 중국인의 나머지 정리
* **제한 사항**: 시간 제한 1초, 메모리 제한 256MB
* **문제 요약**: $$M$$과 $$N$$으로 나누어 떨어지는 주기를 가진 카잉 달력에서 $$<x, y>$$가 주어졌을 때, 이것이 정확히 몇 번째 해($$k$$)인지 구하는 문제. 불가능한 경우 `-1`을 출력한다.

<br>

## 💡 풀이 설계 (Approach)
처음 문제를 읽었을 때는 복잡해 보였지만, 메모장에 예시를 직접 써보며 패턴을 파악하니 방향을 잡을 수 있었다. 

**1. 패턴 파악**
카잉 달력에서 $$k$$번째 해는 기본적으로 $$<k \pmod m, k \pmod n>$$ 년으로 쓸 수 있다. 
다만, $$k$$값이$$m$$이나 $$n$$으로 나누어떨어지는 경우에는 $$0$$이 아닌 $$m, n$$으로 값을 채운다는 규칙이 있다.

**2. 첫 번째 접근: 브루트 포스 (기각)**
가장 먼저 든 생각은 모든 경우의 수를 고려하여 크기가 $$m, n$$인 배열 하나씩을 만든 뒤, 배열을 순회하며 요소를 비교하는 것이었다.
하지만 이 경우 시간 복잡도가 $$O(M \times N)$$이 된다. 주어진 조건($$M, N \le 40,000$$)에서는 연산량이 $$16 \times 10^8$$을 넘어가 무조건 **시간 초과(TLE)**가 발생하므로 빠르게 기각했다.

**3. 최적화 접근: $$O(N)$$ 풀이**
친구와 논의 끝에 새로운 아이디어를 떠올렸다.
$$x$$의 값에 $$m$$을 계속 더해가며 가능한 $$k$$의 후보를 만들고, 그 $$k$$에 대해 상응하는 $$y$$값을 구해서 실제 $$y$$값과 일치하는지 비교하는 방법이다.
이렇게 하면 최대 $$N$$번만 반복하면 되므로, 시간 복잡도를 $$O(N)$$으로 대폭 줄여 제한 시간 내에 해결할 수 있다.

<br>

## 💻 정답 코드 (Code)

```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    m, n, x, y = map(int, input().split())
    flag = False
    
    # x에 m을 더해가며 가능한 k 값 탐색
    for i in range(n + 1):
        k = x + m * i
        check = k % n
        
        # 나누어 떨어질 경우 0이 아닌 n으로 처리
        if check == 0:
            check = n
            
        # 목표한 y값과 일치하는지 확인
        if check == y:
            print(k)
            flag = True
            break
            
    # 유효한 k를 찾지 못한 경우
    if flag == False:
        print(-1)
