## 🚨 웹앱 전환 후 발견된 레이아웃 및 API 버그
ChatGPT를 통해 단 몇 시간 만에 네이티브 코드를 웹앱 형식으로 변환했지만, 실제 구동 결과 대부분의 기능은 잘 동작했으나 UI/UX 측면에서 몇몇 문제들이 발견되었다.

1. **캠퍼스 맵**: 지도가 정상적으로 렌더링되지 않는 현상
2. **게시판 UI**: 댓글 작성 시 키보드가 올라오면 화면 전체가 밀려 올라가는 현상

<br>

## 🐛 원인 파악 및 트러블 슈팅

### 1. 캠퍼스 맵 지도 렌더링 이슈
네이티브 환경과 웹 환경의 지도 호출 방식 차이로 인해 발생한 문제였다.
* **조치사항**: 팀원분이 **카카오맵 API**를 활용하여 웹 환경에 맞게 지도를 다시 구현하였다. 
* **참고**: 카카오맵 API는 일 30만 회까지 무료 호출이 가능하므로, 우리 서비스 규모에서는 충분히 안정적으로 운영이 가능하다.

### 2. 게시판 댓글창 레이아웃 깨짐 (UX 개선)
게시판 코드는 내 담당 영역이었기에 직접 수정을 맡았다. 처음에는 간단한 CSS 수정으로 해결될 줄 알았으나, 웹 브라우저의 기본 설정 값이 코드에서 설정한 값보다 우선순위가 높아 의도대로 동작하지 않았다.
* **조치사항**: 단순 CSS 수정을 넘어 `index.html`의 메타 태그와 뷰포트 설정을 조정하는 등 여러 시도 끝에 댓글창이 활성화되어도 전체 화면이 밀리지 않도록 고정하는 데 성공했다. 
* **느낀 점**: 사소해 보이는 UX 향상에도 예상보다 많은 시간이 소요되어 포기하고 싶었지만, 끝까지 물고 늘어져 해결할 수 있어서 기뻤다.

<br>

## 💦 아쉬운 점과 배운 점
현재 웹앱에서 특정 경고 문구가 뜨고 있는데, 학교 서버의 API를 외부(웹 주소)에서 호출하는 과정에서 발생하는 권한 혹은 보안 이슈로 짐작된다. 

이러한 외부 API 호출 방식은 향후 구글 플레이 스토어 심사에서도 **보안 정책 위반으로 반려될 가능성**이 있다. 만약 반려된다면 아쉽더라도 도서관 기능을 일시적으로 제외하고 재심사를 받거나, 학교 측에 정식으로 API 사용 승인 요청을 할 계획이다.

<br>

## 🚀 앞으로의 계획
이미 앱 버전의 코드는 모든 수정이 완료된 상태다. 내일은 드디어 구글 플레이 콘솔에 **AAB 파일을 업로드**하고 본격적인 출시 심사 대장정을 시작할 예정이다. 

문제를 하나하나 해결해 나가는 이 과정이 결국 나를 성장시킬 것이라 믿는다.
