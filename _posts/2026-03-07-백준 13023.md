## 📌 문제 정보
* **문제 번호**: [백준 13023번: ABCDE](https://www.acmicpc.net/problem/13023)
* **알고리즘 분류**: 그래프 이론, 그래프 탐색, 깊이 우선 탐색(DFS), 백트래킹
* **제한 사항**: 시간 제한 2초, 메모리 제한 512MB
* **문제 요약**: 사람($N$명)과 친구 관계($M$개)가 주어졌을 때, $A-B-C-D-E$로 이어지는 관계(즉, 깊이가 5인 연속된 친구 관계)가 존재하는지 파악하는 문제.

<br>

## 💡 풀이 설계 (Approach)
어제 예고한 대로 스스로 취약하다고 생각하는 '그래프 탐색' 문제를 풀어보았다. 처음에는 문제 자체를 이해하는 것이 쉽지 않았다.

**1. 문제 치환 및 그래프 생성**
몇 번 읽고 난 후, $A, B, C, D, E$가 순서대로 연결되었다는 것은 **"그래프에서 중복되지 않은 정점 5개를 연속으로 탐색할 수 있는가(깊이가 5인 경로가 존재하는가)?"**를 묻는 문제로 치환할 수 있었다.
그래프 생성 자체는 큰 어려움이 없었다. 2차원 리스트를 이용해 인접 리스트를 구현하였고, 친구 관계는 양방향이므로 $A$와 $B$가 주어졌을 때 양쪽에 모두 추가해 주는 것이 핵심이었다.

**2. 난관: BFS vs DFS**
그다음부터 난관에 봉착했다. 처음에는 BFS로 접근했지만, 수많은 경로를 탐색하는 과정 중에 단순한 `for`문만 이용해서 깊이(Count)를 센다는 것이 매우 까다로웠다. 다른 경로를 택하게 되면 탐색 카운트를 초기화하거나 방문 기록을 되돌려야 하는데, 하나의 반복문으로 굴러가는 큐(Queue) 기반의 BFS에서는 구조적으로 구현이 어려웠기 때문이다.

**3. 힌트 참고 및 DFS(백트래킹) 최적화**
이 지점에서 계속 막혀있기보다는 약간의 힌트를 얻기로 결심했다. 인터넷 검색을 통해 이 문제는 깊이를 파고들며 방문을 체크하고 빠져나올 때 다시 해제하는 **DFS(백트래킹)** 구조가 적합하다는 것을 깨달았다. 해당 코드를 참고하여 문제에 맞게 최적화하였고, 모든 노드에서 탐색을 시작해보는 최종 출력 반복문은 직접 구현하여 마무리했다.

<br>

## 💻 정답 코드 (Code)

```python
n, m = map(int, input().split())
friend = [[] for _ in range(n)]

# 양방향 그래프 연결
for _ in range(m):
    a, b = map(int, input().split())
    friend[a].append(b)
    friend[b].append(a)

visited = [False] * n

# DFS 함수 정의
def dfs(x, count):
    # 깊이가 5에 도달하면 True 반환 (A-B-C-D-E 완성)
    if count == 5:
        return True
        
    visited[x] = True # 현재 노드 방문 처리
    
    for v in friend[x]:
        if not visited[v]:
            if dfs(v, count + 1):
                return True
                
    visited[x] = False # 다른 경로 탐색을 위해 방문 처리 해제 (백트래킹)
    return False

flag = 0

# 모든 노드를 시작점으로 하여 탐색 진행
for i in range(n):
    if dfs(i, 1):
        flag = 1
        break

print(flag)
```

## 📝 나의 회고 (Review)
* **문제 풀이 현황**: 그래프 탐색 문제에 취약하다는 것을 스스로 알고 있었기 때문에, 모르는 부분에서 한없이 고민하기보다는 적절한 시점에 힌트를 얻고 그 구조를 확실히 이해하며 발전하는 것이 낫다고 판단했다. 모든 코드를 100% 내 힘으로 짜지 못한 점은 아쉽지만, BFS와 DFS의 용도 차이를 명확히 체감한 아주 값진 경험이었다.
* **다음 계획**: 내일은 대망의 **소프트웨어 마에스트로 2차 코딩 테스트**가 있는 날이다. 그동안 열심히 쌓아온 코딩 감각을 믿고 좋은 성과를 거두고 싶다.

## 🤖 AI 코딩 메이트의 코드 리뷰
* **👍 잘한 점 (백트래킹의 핵심 파악)**: 단순히 DFS를 도는 것에서 끝나지 않고, 함수가 종료되기 직전에 `visited[x] = False`로 방문 처리를 해제하는 '백트래킹(Backtracking)'의 개념을 정확히 이해하고 적용한 점이 매우 훌륭하다. 이 로직이 없었다면 다른 경로로 이어지는 새로운 $A-B-C-D-E$ 패턴을 찾지 못했을 것이다.
* **💡 전략적 조언 (SQL 복습)**: 내일 오전에 코딩 테스트를 위해 SQL 문법을 빠르게 훑어보겠다는 계획은 무척 탁월하다. 코딩 테스트 대비뿐만 아니라, 이번 봄학기에 수강하고 있는 핵심 전공인 **'데이터베이스 시스템'** 과목을 수월하게 따라가기 위한 훌륭한 예습이 될 것이다.
