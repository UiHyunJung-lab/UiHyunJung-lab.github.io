## 📌 문제 정보
* **문제 번호**: [백준 1748번: 수 이어 쓰기 1](https://www.acmicpc.net/problem/1748)
* **알고리즘 분류**: 수학, 구현, 브루트포스 알고리즘
* **제한 사항**: 시간 제한 0.15초, 메모리 제한 256MB
* **문제 요약**: 1부터 $N$까지의 수를 이어서 쓰면 새로운 하나의 수를 얻게 된다. 이때 새로 만들어진 수의 자릿수를 구하는 문제.

<br>

## 💡 풀이 설계 (Approach)
백준 문제 티어 기준 '실버 4'로 비교적 쉬운 편의 문제였고, 어렵지 않게 해결할 수 있을 것이라 판단했다. 메모장에 몇 가지 예시를 직접 써보며 자릿수 패턴을 파악하여 접근했다.

**1. 자릿수 파악하기**
가장 먼저 주어진 숫자 $N$의 자릿수를 구해야 한다. 처음에는 `while` 반복문을 이용해 숫자를 10으로 나누어 가며 자릿수를 구하는 수학적인 방식을 떠올렸으나, 파이썬(Python)을 사용하고 있기 때문에 코드를 더 짧게 단축하기로 했다. 숫자를 문자열로 변환한 후 길이를 재는 `len(str(n))` 방식을 채택했다.

**2. 자릿수별 개수 패턴 파악**
* 1자리 수 (1~9): 9개
* 2자리 수 (10~99): 90개
* 3자리 수 (100~999): 900개

위 패턴에 착안하여, 주어진 숫자 $N$의 자릿수($L$)보다 작은 자릿수들은 `for` 반복문을 통해 한 번에 더해준다. 

**3. 남은 자릿수 더하기**
목표 자릿수($L$)에 도달하면, 해당 자릿수에서 $N$까지 몇 개의 숫자가 있는지 센 뒤 $L$을 곱하여 총합에 더해 최종 답을 구했다.

<br>

## 💻 정답 코드 (Code)

```python
import math

n = int(input())
l = len(str(n))
k = pow(10, l-1)
ans = 0

# n의 자릿수보다 적은 자릿수들의 총 자릿수 합
for i in range(1, l):
    ans += i * 9 * pow(10, i-1)

# n과 같은 자릿수를 가진 숫자들의 자릿수 합
ans += (n - k + 1) * l

print(ans)
```

## 🤖 AI 코딩 메이트의 코드 리뷰
작성한 정답 코드에 대해 객관적인 피드백과 개선점을 분석해 보았다.

* **👍 잘한 점 (파이썬의 특성 활용)**: C++이나 Java였다면 반복문으로 나눗셈을 했겠지만, 문자열의 길이를 구하는 `len(str(n))`을 활용하여 불필요한 반복문을 없애고 코드를 직관적으로 짠 점이 아주 훌륭하다. 알고리즘 문제를 풀 때 언어의 장점을 살리는 것은 실전에서 시간을 단축하는 핵심 스킬이다.
* **⏱️ 시간 복잡도 분석**: $N$이 아무리 커도 자릿수 길이만큼만 반복문이 실행된다. $N$이 1억이더라도 최대 8번만 순회하므로, 이 코드의 시간 복잡도는 $O(\log_{10} N)$이 되어 0.15초의 빡빡한 제한 시간을 아주 여유롭게 통과한다.
* **💡 코드 개선 팁 (연산자 최적화)**: 현재 `import math`를 통해 `pow()` 함수를 사용하고 있는데, 파이썬에 내장된 거듭제곱 연산자인 `**`를 사용하면 모듈을 임포트할 필요도 없고 연산 속도도 미세하게 더 빠르다. 즉, `10 ** (l-1)`로 작성하면 더욱 깔끔한 코드가 된다.
