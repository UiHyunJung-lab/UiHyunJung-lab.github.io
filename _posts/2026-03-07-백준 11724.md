## 📌 문제 정보
* **문제 번호**: [백준 11724번: 연결 요소의 개수](https://www.acmicpc.net/problem/11724)
* **알고리즘 분류**: 그래프 이론, 그래프 탐색, 깊이 우선 탐색(DFS), 너비 우선 탐색(BFS)
* **제한 사항**: 시간 제한 3초, 메모리 제한 512MB
* **문제 요약**: 방향 없는 그래프가 주어졌을 때, 서로 연결되어 있는 덩어리인 '연결 요소(Connected Component)'의 개수를 구하는 문제.

<br>

## 💡 풀이 설계 (Approach)
오늘도 그래프 탐색 문제를 풀었다. 문제 제목을 보고 살짝 놀랐는데, 왜냐하면 어제 문제를 풀면서 힌트를 얻고 참고했던 코드가 바로 이 문제와 관련된 것이었기 때문이다. 덕분에 풀이의 방향성을 찾는 데 오랜 시간이 걸리지 않았다.

**1. 그래프 생성 및 알고리즘 선택**
그래프를 만드는 과정까지는 어제 풀었던 문제와 정확히 동일했다. (양방향 간선 처리) 
이후 탐색의 경우, 연결할 수 있는 곳까지 최대한 뻗어나가며 이어줘야 하므로 **DFS(깊이 우선 탐색)**를 선택했다.

**2. DFS 로직 구현**
기본적인 DFS 코드의 뼈대처럼, 특정 정점을 방문 처리한 뒤 그 정점과 이어져 있는 정점들 중 '아직 방문하지 않은 정점'에 대해 재귀적으로 DFS를 실행하도록 구현했다.

**3. 연결 요소(Connected Component) 카운팅**
모든 정점($$1 \dots N$$)을 순회하며 방문하지 않은 정점이 발견될 때마다 연결 요소의 개수(`count`)를 1 추가하고, DFS를 실행해 연결된 모든 정점을 한 번에 방문 처리하는 방식으로 코드를 완성했다.

<br>

## 💻 정답 코드 (Code)

```python
import sys
sys.setrecursionlimit(10**6)
input = sys.stdin.readline

n, m = map(int, input().split())
G = [[] for _ in range(n+1)]

# 양방향 그래프 연결
for _ in range(m):
    u, v = map(int, input().split())
    G[u].append(v)
    G[v].append(u)
    
count = 0
visited = [False] * (n + 1)

# DFS 함수 정의
def dfs(x):
    visited[x] = True
    for a in G[x]:
        if not visited[a]:
            dfs(a)

# 모든 정점을 돌면서 연결 요소 확인
for i in range(1, n+1):
    if not visited[i]:
        dfs(i)
        count += 1
        
print(count)
```

* **👍 잘한 점 (메타 인지와 패턴 학습)**: 어제 공부한 내용을 곧바로 다른 문제에 적용해 낸 것은 훌륭한 학습 과정이다. 누군가의 코드를 한 번 보고 끝내는 것이 아니라, DFS의 뼈대를 정확히 이해하고 '연결 요소'를 카운팅하는 전체 로직을 스스로 설계해 낸 것은 분명한 실력 향상이다. 
* **⏱️ 시간 복잡도와 파이썬 최적화**: 모든 정점($$N$$)과 간선($$M$$)을 한 번씩만 탐색하므로 시간 복잡도는 $$O(N + M)$$이다. 특히 파이썬으로 깊이가 깊은 DFS를 짤 때 발생할 수 있는 런타임 에러를 방지하기 위해 `sys.setrecursionlimit(10**6)`을 미리 세팅한 점은 실전에서 아주 강력한 기본기가 될 것이다.
